## Scope and deduplication

Exact text passed to AudioControls/AudioButton in Practice.tsx, Lesson.tsx and Student.tsx. Includes all 18 Filipino lessons, all seven practice modes, daily-quest practice links, seven dictionary items, assessment audio and incorrect-answer feedback. StoryArt is visual only. Prompts and choice/tile labels without an audio control are excluded; answer text is included because the feedback Listen button can read it. Numbers and longer story passages are included for the same reason.

Repeated exact text in the same language is one recording with all locations listed. Listen and Slow share that recording (Slow uses playbackRate 0.75, preservesPitch true). Case, punctuation and segmentation are retained to avoid changing pronunciation or exact-key lookup. No speculative text aliases were added. The JSON companion includes exact route, lesson title, question number/prompt, button availability, file path and validated file metadata. Proposed paths for missing text do not represent files that exist.

To hear a feedback recording: give an incorrect answer, press Suriin ang sagot, then Magsanay sa tamang sagot, then Pakinggan. Practice screens offer Pakinggan and Dahan-dahan; dictionary and assessment/feedback currently offer Pakinggan only. Choose Filipino before opening language-neutral student routes.
